Tôi cần bạn xây dựng một ứng dụng Web "Social Network" hoàn chỉnh sử dụng PHP, MySQL, Nginx và Linux.

REQUIREMENTS:

DATABASE:
- Tạo database "socialnet"
- Tạo bảng "account": id (INT PK), username (VARCHAR 50 UNIQUE), fullname (VARCHAR 100), password (VARCHAR 255), description (TEXT), created_at (TIMESTAMP)
- Tạo file db.sql chứa toàn bộ SQL commands

PROJECT STRUCTURE:
/admin/newuser.php - Form tạo user mới (validate, hash password, insert DB)
/socialnet/signin.php - Login page (validate, check password, create session)
/socialnet/index.php - Home page (check login, show current user info, list all users with links to profile)
/socialnet/profile.php - Profile page (accept ?owner query string, show user info & description)
/socialnet/setting.php - Edit profile page (form to edit description, save to DB)
/socialnet/about.php - Static page (show student name & number)
/socialnet/signout.php - Logout (destroy session, redirect)
/includes/config.php - DB configuration & connection
/includes/functions.php - Helper functions
/includes/menubar.php - Reusable navbar (links: Home, Setting, Profile, About, SignOut)
/includes/session.php - Session management functions
/assets/style.css - Professional styling
/assets/script.js - Optional JS helpers
README.md - Setup instructions
.gitignore - Git ignore file

MENUBAR (in home/profile/setting/about pages):
- Home → /socialnet/index.php
- Setting → /socialnet/setting.php
- Profile → /socialnet/profile.php
- About → /socialnet/about.php
- SignOut → /socialnet/signout.php
